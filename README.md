# موقع الأستاذ إيهاب حجاب

موقع React + Vite لتعليم الفيزياء للمرحلتين الثانية والثالثة الثانوية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

## النشر على GitHub وVercel

ارفع محتويات هذا المجلد إلى GitHub، ثم اربط المستودع بمشروع Vercel.

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: اتركه فارغًا إذا كان `package.json` في جذر المستودع

عند حجز درس، يفتح الموقع واتساب تلقائيًا ببيانات الطالب.
