## رفع المشروع على Vercel:
1. ارفع المشروع بالكامل إلى GitHub.
2. افتح https://vercel.com
3. اضغط على New Project.
4. اختر المستودع الخاص بك.
5. تأكد أن Framework Preset = Next.js.
6. اضغط Deploy.
